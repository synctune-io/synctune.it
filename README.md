# Synctune

The company website for [synctune.it](https://synctune.it): home, complete
portfolio, and company pages. Plain HTML, CSS and a small optional directory
filter. No dependencies, install command or build step.

- [Preview and manual Pages deployment](docs/deployment.md)
- [Content, project links and brand assets](docs/maintenance.md)

The repository root is the publish directory. Nothing deploys automatically.
